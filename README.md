# 🎨 Colorizing Black and White Images using Deep Learning

## Overview
This project focuses on colorizing grayscale (black and white) images using deep learning techniques. It uses Convolutional Neural Networks (CNNs) to predict and add realistic color to monochrome images, enhancing their visual appeal and restoring historical photographs.

## Features
- Automatically colorizes black and white images using CNN-based architecture
- Works on a wide range of image types, including portraits and landscapes
- Easy-to-use code structure with customizable model and dataset

## Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
